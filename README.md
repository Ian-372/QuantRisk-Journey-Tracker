# QuantRisk Journey Tracker

A no-build vanilla HTML/CSS/JavaScript career tracker for an Actuarial Science student targeting:

**Quantitative Risk & Financial Analytics**

Technical specialization:

**Python + SQL + Data Engineering + Machine Learning + AI**

## Run

Open `index.html` in a browser, or use VS Code Live Server.

## Included

- Dashboard with overall mastery
- Year 3.1 → Year 4.2 roadmap
- Six-layer career architecture
- Skill mastery matrix
- Six-stage evidence ladder for every skill: Learn → Practice → Build → Test → Interview → Master
- Recommended next action based on the least-developed skill
- Portfolio project roadmap
- Interview lab
- Evidence/mastery checks
- Streak tracking
- Dark/light mode
- Local browser persistence

## Important design principle

This tracks **demonstrated mastery**, not course completion.

The intended progression is:

Learn → Practice → Build → Test → Interview → Master
